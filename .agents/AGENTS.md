# Project Rules & Guidelines for Play LooP

1. **Dual Environment Parity (Local & Deployed)**:
   - Always ensure all features, audio streaming pipelines, and UI changes work equally well on both local development (`localhost`) and live deployed cloud environments (Render / Docker / Mobile PWA).

2. **Proactive Architectural Advice & Confirmation**:
   - Before executing code changes, if there is a better option, potential issue, or architectural trade-off, **explain the options first and ask for user confirmation**.

3. **No Unrequested Code Edits**:
   - Never modify codebase files without explaining the rationale and obtaining explicit user confirmation.
